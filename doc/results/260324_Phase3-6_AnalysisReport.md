# 260324 리디자인 Phase 3-6 통합 분석 보고서

## 1. 개요
경매 핵심 인터랙션(입찰, 채팅)과 정보 시각화(게이지, 진행률)를 강화하고, 전체 레이아웃의 반응형 완성도를 높여 'Cyber-Pixel' 테마를 완성한다.

## 2. 컴포넌트별 분석
### 2.1. BiddingControl (인터랙션 강화)
- **현황**: 기본적인 입찰 기능은 작동하나, 시각적 피드백이 정적임.
- **목표**: 48px 이상의 터치 타겟 확보 및 `isLeading` 상태 시 골드 광택 애니메이션 적용.
- **기술**: CSS `before` 가상 요소와 `translateX` 애니메이션 활용.

### 2.2. ChatPanel (시각 분리)
- **현황**: 시스템 메시지와 유저 메시지가 명확히 구분되지 않아 가독성이 떨어짐.
- **목표**: '게임 이벤트 로그' 스타일 적용. 시스템 메시지는 강조 배지와 배경색을, 유저 메시지는 말풍선 스타일을 적용함.
- **기술**: `MessageItem` 컴포넌트 분기 처리 강화.

### 2.3. TeamList & 게이지 (정보 시각화)
- **현황**: 포인트가 숫자로만 강조되어 잔액 수준 파악이 어려움.
- **목표**: 픽셀 스타일의 게이지 바 적용. 60%/30%/0% 단계별 색상 변화 및 `pulse` 애니메이션 적용.
- **기술**: Tailwind `transition-all` 및 `duration-[2000ms]`를 통한 부드러운 전이.

### 2.4. CreateRoomModal (진행률 표시기)
- **현황**: 다단계 폼 진행 시 현재 위치 파악이 직관적이지 않음.
- **목표**: 상단에 픽셀 미니언이 움직이는 트랙형 진행률 표시기 추가.
- **기술**: `Framer Motion` 또는 CSS `transform`을 이용한 미니언 위치 이동.

## 3. 레이아웃 및 폴리싱
- **모바일 최적화**: `order-*` 클래스를 활용하여 보드 -> 채팅 -> 팀 리스트 순으로 재배치.
- **아코디언**: 모바일에서 팀 리스트를 접고 펼칠 수 있는 토글 버튼 구현.
- **Delight**: `SoldOverlay` 전체화면 낙찰 효과 및 파티클 시스템 적용.
